# Bitrix Production Code Examples (Enterprise Services)

В данном репозитории собраны примеры кастомных сервисов, интеграционных модулей и бизнес-компонентов для **1С-Битрикс (ядро D7)**. Код спроектирован с учетом современных стандартов веб-разработки, требований к отказоустойчивости, безопасности данных и оптимизации высоконагруженных SQL-запросов.

---

## 🛠️ Архитектурные стандарты проекта
* **PSR-4 и Строгая типизация:** Весь код распределен по пространствам имен (`App\Services\...`), типизирован и подготовлен для автоматической загрузки.
* **Принцип SOLID и Decoupling:** Бизнес-логика изолирована от конкретных реализаций (сетевых клиентов, сторонних API и сырых массивов СУБД) через интерфейсы и транспортные слои.
* **Безопасность (ИБ-аудит):** Полностью исключено использование суперглобальных массивов (`$_REQUEST`, `$_GET`). Сбор параметров реализован через объектные обертки фреймворка.

## 📁 Содержимое репозитория

### 1. Сервис синхронизации и коммерческого расчета курсов валют
* **Путь к файлу:** `src/Services/Currency/CurrencyService.php`
* **Описание:** Компонент автоматического парсинга данных Центробанка РФ, расчета коммерческого курса (с учетом маржинальности банка) и синхронизации с базой данных (Highload-блоки).
* **Ключевые инженерные решения:**
    * **Оптимизация алгоритма сопоставления (O(1)):** Данные за предыдущие периоды предварительно индексируются по коду валюты (`CharCode`), что исключает вложенные циклы при расчете дельты изменений.
    * **Управление исключениями:** Заменены легаси-конструкции аварийного завершения скрипта (`die`). Ошибки логируются, а критические сбои пробрасывают штатные `SystemException`.
    * **Фоновое выполнение:** Архитектура метода `generateAndSaveTable()` подготовлена для выноса на уровень **Битрикс-агентов (Cron)**, что исключает блокировку веб-потоков пользователей при сбоях внешнего API ЦБ.

### 2. Клиент интеграции с HR-платформами (REST API & Паттерн DTO)
* **Путь к файлу:** `src/Services/Recruitment/VacancyIntegrationService.php`
* **Описание:** Клиент для автоматической агрегации вакансий организации с внешнего шлюза HeadHunter API и вывода их на карьерной странице сайта.
* **Ключевые инженерные решения:**
    * **Паттерн Data Transfer Object (DTO):** Сырые JSON-ответы внешнего сервиса гидрируются в иммутабельные объекты `VacancyDataTransferObject`. Это полностью отвязывает внутренние шаблоны сайта от изменений в структуре стороннего API.
    * **Инверсия зависимостей (DIP):** Класс реализует контракт `RecruitmentProviderInterface`. Приложение зависит от абстракции, что позволяет бесшовно переключить шлюз на другую платформу (SuperJob, Avito или внутреннюю ATS) без рефакторинга контроллеров.
    * **Безопасность соединения:** Инкапсулирована конфигурация сетевых таймаутов (`timeout` / `connect_timeout`) для защиты веб-сервера от зависания при падении внешнего шлюза.

### 3. Компонент сквозного админ-поиска и генератор Excel-отчетов
* **Путь к файлам:**
    * Поисковое ядро: `src/Services/Content/Search/AdminSearchService.php`
    * Модуль экспорта: `src/Services/Content/Search/ExportSpreadsheetService.php`
* **Описание:** Высокопроизводительный модуль для поиска элементов по текстовым полям и свойствам инфоблоков Битрикс с последующей генерацией выгрузок.
* **Ключевые инженерные решения:**
    * **Ликвидация проблемы N+1 SQL-запросов (Eager Loading):** Устранено критическое узкое место, при котором метаданные инфоблоков запрашивались в цикле индивидуально для каждой строки. Реализован пакетный сбор ID из коллекции — данные подтягиваются одним SQL-запросом и распределяются из кэша.
    * **Принцип DRY (Don't Repeat Yourself):** Логика поиска для веб-интерфейса и файловой выгрузки объединена в рамках единого репозитория `ElementRepository`. Конфигурация пагинации (`PageNavigation`) является опциональной.
    * **Слой представления (Spreadsheet Export):** Процедурный код генерации документов изолирован в сервис `ExportSpreadsheetService`. Реализовано динамическое масштабирование колонок на базе библиотеки `PhpSpreadsheet`.
